    Подключить спутник

    Введите собственный ArcGIS API key. Он сохранится только в этом браузере на этом устройстве и не отправляется на сервер Mercury Plus.

    В ключе должен быть доступ к Static Basemap Tiles (privilege: premium:user:staticbasemaptiles). Ограничьте ключ по HTTP referrer вашим доменом в настройках Esri. Не используйте секретный серверный ключ в браузере.

    About this pilot

    Mercury Plus is an early public, non-commercial browser pilot for exploring Ho Chi Minh City. The pilot includes an OpenStreetMap street map and optional Esri World Imagery satellite imagery using a visitor-provided API key. Other city datasets are being checked for source quality, access conditions and licence requirements.

    This interface is experimental. It is not an emergency-response service and must not be used as the sole basis for safety-critical decisions.
